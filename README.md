# 財管筆記｜Finance Wiki

繁體中文財務管理入門知識庫，包含貨幣時間價值、財務報表、現金流、NPV、IRR、WACC、風險與報酬、CAPM、投資組合等九篇文章。

## 功能
- 分類篩選與即時搜尋
- 共用文章閱讀頁
- 深色模式
- 響應式手機／平板／桌面版
- `AGENTS.md` 規範 AI 後續新增文章

## 使用與發布
直接開啟 `index.html` 即可使用。要發布至 GitHub Pages，請在 GitHub 建立新公開 repository（例如 `finance-wiki`），將所有檔案上傳至 repository **根目錄**，前往 Settings → Pages → Deploy from a branch，選 `main` 與 `/(root)`，按 Save。

注意：這是與既有「材料科學」網站分開的新專案，請勿直接覆蓋原來的 `mnote`，除非你確定要替換原網站。

## 擴充方法
閱讀 `AGENTS.md`，在 `data.js` 的 `window.ARTICLES` 新增符合格式的文章；不必另外建立 HTML，搜尋與分類會自動包含新文章。

本網站供教育學習用途，不構成投資建議。
